CONCLUSIONS
  wIndex = input number minus 1 (0,1 = mic inputs 1,2; 2,3 = line inputs 3,4).
  TotalMix writes all four gains in every burst, not just the one that changed.

  Mic inputs (wIndex 0,1), 0..65 dB - packed, same on input 2 as input 1:
    coarse = min(dB / 3, 20)   bits 0-4
    fine   = dB - 3 * coarse   bits 5-7
    wValue = (fine << 5) | coarse
    input 2: 10 dB -> 0x23, 61 dB -> 0x34  (match formula)

  Line inputs (wIndex 2,3), 0..9 dB in TotalMix - NOT packed:
    wValue = dB * 2            (1->0x02, 2->0x04, 3->0x06, 9->0x12, input 4: 5->0x0a)
    Max 9 dB -> raw 18 (0x12), fits in 5 bits. Units are 0.5 dB - confirmed in
    bbf-gain-finesteps (4.5 dB -> 0x09). TotalMix snaps line gain to 0.5 dB, mic to 1 dB.
