DECODED MIC GAIN ENCODING (req 0x1a, wValue at wIndex 0):

  coarse = min(dB / 3, 20)        integer division, 3 dB steps, 0..20  -> bits 0-4
  fine   = dB - 3 * coarse        0..2 normally, 0..5 above 60 dB       -> bits 5-7
  wValue = (fine << 5) | coarse

  So the low 5 bits only give 21 coarse steps (0..60 dB in 3 dB steps);
  bits 5-7 carry the remainder. Above 60 dB coarse stays at 20 and fine goes 3,4,5.
